UX/UI Field Cheat Sheet

Laws of Interaction · ch. 02

  • Fitts — big targets, near the thumb; edges are infinite
  • Hick — every extra option taxes every user, every time
  • Jakob — users arrive trained by other apps; spend novelty on one thing
  • Miller — 4–7 chunks; never carry info between screens by memory
  • Tesler — complexity moves, never vanishes; absorb it into defaults
  • Peak–end — polish the best moment and the ending hardest

Nielsen’s Ten · ch. 03

  • 1 Status visible · 2 Real-world language
  • 3 Undo & exits · 4 Consistency
  • 5 Prevent errors · 6 Recognition > recall
  • 7 Expert accelerators · 8 Minimalist
  • 9 Recoverable errors · 10 Contextual help

Hierarchy Levers · ch. 05

  • Size — one hero per screen
  • Weight/contrast — gray before smaller
  • Space — margin is a spotlight
  • Position — message top, action bottom
  • Color — one accent, spent like money
  • Verify — squint test: 3 levels survive

The Hand & The Numbers · ch. 07–08

  • Touch targets≥44pt iOS · ≥48dp Android
  • Thumb zoneprimary bottom · destructive far
  • Contrast, body text≥4.5:1 (aim 7:1)
  • Contrast, large/UI≥3:1
  • Type testlargest AX size — no truncation
  • Feedback<100ms ack · >1s indicator · >10s escape

The Process · ch. 09

  • 1 Frame it in one sentence
  • 2 Map top-3 flows as intentions
  • 3 Choose the IA (the expensive call)
  • 4 Wireframe the core loop, real content
  • 5 Split into HIG / M3 dialects
  • 6 Design empty · error · offline · first-run
  • 7 Audit, test with 5, loop

First Session · ch. 25–26

  • Value → first win → then sign-up → permission in context
  • Empty states: teach / celebrate / redirect
  • Push bar: theirs · timely · actionable
  • Never batch permission dialogs at launch

The Screen Audit · ch. 31 — run on every screen

  • One primary action?
  • Obvious in 5 seconds?
  • Thumb test passed?
  • Targets ≥ 44pt / 48dp?
  • Every state designed?
  • Feedback within 100 ms?
  • Undo over confirm?
  • Recognition over recall?
  • Contrast & type accessible?
  • Keyboard respected?
  • Platform dialect spoken?
  • State survives interruption?
